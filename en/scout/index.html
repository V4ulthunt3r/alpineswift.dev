Scout

The quality check before every release.

Scout checks your Swift and SwiftUI projects before they go to the store: lint rules, build, tests and coverage in one run, locally on your Mac. You end up with a report that shows what got better and what is still missing.

Why Scout

When AI writes along, someone has to proofread.

AI tools produce a lot of code, fast. Whether it is clean, tested and maintainable often only shows after launch. Scout makes it visible beforehand, without your code ever leaving your machine.

One run, every check

SwiftLint, build, tests and measured coverage from your Xcode schemes. No piecing results together from four terminal windows.

Progress, not a snapshot

Every run is saved. Scout compares against a baseline you choose and shows which findings are new and which are resolved.

Local and provable

Checksums before and after every run prove which source state was checked. The code stays on your Mac.

Features

What Scout does.

Profiles from Xcode

Scout reads schemes, configurations and test destinations from the project and saves them as a reusable check profile.

Your own rules

Turn default rules on and off, add custom regex rules with message and severity, exclude paths. Without touching project files.

Best-practice catalogue

Recommendations for Swift and SwiftUI with sources and clearly stated limits. Selected rules run as an extra check per project.

Findings that move with the code

When code shifts, Scout re-matches unchanged finding lines through stored hashes. The comparison stays meaningful.

Reports for people and agents

Export as HTML for reading and JSON for tools, plus a Markdown guide on how to read the report.

AI repair brief

A check run becomes a ready-made prompt: copy it or save it as a Markdown file and hand it to your coding assistant.

Shared by all three tools

Built like our apps.

Through the embedded adapter scout-mcp, a local assistant sees the profiles and metrics of a shared project and can propose rule changes. Scout never hands out source code or account data, and a rule only changes once you accept the proposal in Scout.

  • Local first

    Your data lives on your devices. No Alpine Swift account and no server of ours in between.

  • Native to Apple

    Built with Swift and SwiftUI, with light and dark mode and the interaction patterns you know from Apple.

  • Assistants welcome

    Every tool ships a local MCP interface. AI assistants may read, check and suggest.

  • You decide

    Nothing is applied, published or submitted unless you confirmed it yourself. No silent automation.
